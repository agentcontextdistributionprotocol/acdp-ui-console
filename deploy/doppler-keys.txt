# Keys deploy/doppler-sync.sh pushes from Doppler (acdp-ui-console/prd) into
# the Vercel project zer07labs/acdp-ui-console, Production environment.
# Doppler owns exactly these; the script never touches any other Vercel
# variable, never removes one, and leaves Preview and Development alone.
#
# One key per line. "KEY sensitive" creates the key as a Vercel sensitive
# (write-only) variable when it is new. The keys that existed before the
# Doppler migration are sensitive Production-only entries (Preview has its
# own, smaller set: docs/deployment.md), so the sync reports them and leaves
# them alone (see the script header); Doppler holds the same values, checked
# by behaviour against production at migration time.
#
# Left out on purpose: NEXT_PUBLIC_APP_VERSION (no app code reads it on
# Vercel, it is a Docker build arg, and its Vercel value is unreadable), and
# REGISTRY_A/B_BASE_URL (unused since registry reads go through the
# playground's passthrough; the sync never deletes, so their Vercel entries
# remain until removed by hand).
